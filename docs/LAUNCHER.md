# `TE1_Mod_Launcher.bat` — один лаунчер на все моды

Один `.bat`-файл, английский интерфейс. Кладётся **в папку с игрой**
(рядом с `TheEscapists.exe`), сам проверяет, что игра действительно рядом,
создаёт папку `mods` и показывает меню.

Главное правило: **моды действуют только когда игра запущена через лаунчер.**
Лаунчер накладывает моды, запускает игру, ждёт, пока ты её закроешь, и
возвращает `Data\*.dat` в исходное состояние. Запустил игру из Steam —
получил чистой игры, без всяких модов.

## Меню

```
  THE ESCAPISTS 1 - MOD LAUNCHER
  ============================================================
   1. Launch Game With Mods
   2. Mod Workshop
   3. Exit

  MOD WORKSHOP
   1. Randomizer          [INSTALLED / not installed]
   2. Better Translate    [INSTALLED / not installed]
   3. Back

  RANDOMIZER
   Status: INSTALLED
    1. Uninstall          <- или "Install", если мод выключен
    2. Back
```

`Launch Game With Mods` без установленных модов честно скажет об этом и
предложит зайти в Mod Workshop.

## Установка

1. Скопируй `TE1_Mod_Launcher.bat` в папку игры — туда, где лежит
   `TheEscapists.exe` и подпапка `Data`.
   Обычно это `C:\Program Files (x86)\Steam\steamapps\common\The Escapists`.
2. Нужен **Python 3** — https://www.python.org/downloads/
   (при установке поставь галочку **Add Python to PATH**).
3. Двойной щелчок по `.bat`. Если игра стоит в `Program Files`, Windows
   спросит права администратора — разреши. Без них писать в `Data` нельзя,
   и лаунчер сам об этом скажет.

Всё остальное (движок модов, таблица переводов) запаковано в сам `.bat`
и распаковывается при каждом запуске.

## Что появляется в папке игры

```
TheEscapists.exe
Data\                    <- рабочие файлы игры
mods\                    <- создаётся лаунчером
   mods.json             <- какие моды включены
   te1_engine.py         <- движок, распакованный из .bat
   original\             <- нетронутые копии всех файлов, которые правим
```

`mods\original\` — это твоя страховка. Из него лаунчер и восстанавливает
оригиналы. Если снести всю папку `mods`, лаунчер просто создаст её заново
и заново снимет копии.

Откат в любой момент руками:

```
py mods\te1_engine.py --restore
```

## Мод 1: Randomizer

Перетасовывает игровые статы всех предметов: `Weapon`, `Digging`,
`Chipping`, `Cutting`, `Unscrewing`, `HP`, `FAT`, `Gift`, `Decay`, `Buy`
и нелегальность. Каждому предмету достаётся случайный набор из 1–4
характеристик со случайными значениями.

**Срабатывает при каждом запуске игры с модами** — закрыл игру, запустил
снова через лаунчер — получил новый набор. Никаких кнопок жать не надо.

Что **не** трогается: `Name`, `Info`, `Craft`, `Found`, `Outfit`, `Desk`,
`NPC_carry`, `CamDis`. То есть названия, описания и рецепты остаются
читаемыми, крафт продолжает работать, формы и тайники не съезжают.

Правится каждый `items_*.dat`, какой найдётся в `Data` (игра читает ровно
один — тот, что под язык запуска, — а какой именно, заранее не известно).

## Мод 2: Better Translate

Чинит официальный русский перевод. Эталон для сравнения — `*_eng.dat`
из той же папки `Data`. Правятся `items_rus.dat`, `data_rus.dat`,
`speech_rus.dat`.

На присланных файлах мод делает **469 правок**:

| файл | что сделано |
|---|---|
| `items_rus.dat` | 74 правки имён, описаний и рецептов |
| `data_rus.dat` | 154 строки исправлено, 1 строка добавлена |
| `speech_rus.dat` | 155 строк исправлено, 85 строк добавлено |

По типам:

**1. Строки, которых в русском файле вообще не было (86 штук).**
Игра либо показывала пустое место, либо английский текст. Например, из
24 реплик медперсонала (`[MedStaff]`) переведено было только 5 — остальные
19 добавлены. То же с `[Sheets]` (было 2 из 10), `[OnDesk]`, `[DropIt]`,
`[ET_Banter_Cage]`, `[SS_Banter]` и ещё двумя десятками секций. Счётчик
`Count` в секции при этом обновляется, иначе игра эти строки не увидит.

**2. Непереведённый английский.** 25 мест в предметах
(`Info=Unlocks yellow doors`, `Name=Dirty Tux Outfit`) и 4 в `data_rus.dat`
(`Misc 54=Store`, кредиты `Misc 34`, `SS Hover_Reindeer`).

**3. Машинный перевод имён предметов.** Калька с английского, где порядок
слов не переставлен:

| было | стало |
|---|---|
| `Пластиковый работа ключевая` | `Пластиковый ключ рабочего` |
| `Пластиковый утилита ключ` | `Пластиковый технический ключ` |
| `Пластиковый охранник ключ` | `Пластиковый ключ охраны` |
| `Узник равномерное` / `Солдат равномерное` | `Форма узника` / `Форма солдата` |
| `смокинг Наряд` / `приспешник Наряд` | `Наряд-смокинг` / `Наряд приспешника` |
| `Эльф одежда` / `Эльф охранник одежда` | `Одежда эльфа` / `Одежда эльфа-охранника` |
| `Почистить нож` (Shoe Knife) | `Нож в ботинке` |
| `Заточить чайный поднос` (Sharp Tea Tray) | `Заточенный чайный поднос` |
| `Устранение лазерной системы слежения` (Cutting Laser Watch) | `Часы с лазерным резаком` |
| `Файл` (File — инструмент!) | `Напильник` |
| `Пробковое дерево` (Balsa Wood) | `Бальзовое дерево` |
| `участок` ×3 (Package) | `Посылка` ×3 |

Плюс перепутанные местами заготовки ключей: `59` («Заготовка ключа
рабочего») и `83` («Заготовка ключа от камеры») в русском файле стояли
наоборот, из-за чего рецепты `58` и `87` ссылались не на то. Всё это
исправлено вместе с рецептами — рецепт в игре хранится **текстом имени**,
поэтому переименование предмета без правки рецептов ломает крафт.

**4. Сломанные `$переменные`.** В Tutorial для Mac вместо `$combat`
стояло переведённое `$бой` — игра показывала буквально «$бой». Там же
потеряны `$name`, `$int`, `$inmates`, `$giver`.

**5. Съехавшие префиксы подсказок.** Строки обучения начинаются с `N@`
(сколько строк занимает подсказка); в русском файле почти везде стояло
на единицу больше, чем в английском. Префиксы приведены к оригиналу.

**6. Латиница внутри русских слов.** `К тому жe..`, `#Hажми`,
`на продажy` — там, где латинская буква примыкает к кириллической, она
заменяется на кириллическую. Бренды (`VIP`, `DVD`, `Worms`, `Jingle Cells`)
трогать нельзя — и не трогаются: правило срабатывает только по соседству
с кириллицей.

**7. Мусор в тексте.** Неразрывные пробелы (`U+00A0`) — 7 штук,
одиночные переводы строк внутри значения вместо `#` (маркера перевода
строки в этой игре) — 7 штук, «. . .» вместо «...», пробелы перед `!`,
`?`, `,` и перед `#`, хвостовые пробелы (их только в репликах больше
сотни).

**8. Опечатки и кривые фразы.** `поплатиться` → `поплатится`,
`работаЯ` → `работа`, `Я видел, что $name!` → `Я все видел, $name!`,
`Документы не подписаны !` → `Эти бумаги даже не подписаны!`,
перевранное приветствие надзирателя в Shankton State Pen,
оборванные подсказки таксофона, не туда переведённые реплики `[Banter]`
и рецепты танка в `escTeam`.

**9. Строчные буквы в пунктах меню.** `новая игра`, `назад`,
`полноэкранный`, `оконный`, `готово`, названия работ и параметров —
всего около 60 строк. Если в английском файле строка начинается с большой
буквы, в русской она тоже становится с большой.

## Как это устроено внутри

```
TE1_Mod_Launcher.bat          <- ОДИН файл, pure ASCII, CRLF
   |
   |  cmd: проверяет TheEscapists.exe, создаёт mods\,
   |       ищет Python, просит права администратора
   |  powershell: вынимает блок между #<ENGINE> и #</ENGINE>
   v
mods\te1_engine.py            <- движок (Python 3, только стандартная библиотека)
   |
   +-- launcher_src/fixes_rus.json   <- таблица переводов (запакована внутрь)
```

Всё, что касается русского языка, лежит в `launcher_src/fixes_rus.json` —
это обычный UTF-8 JSON, его удобно править и ревьюить. В `.bat` он
попадает в виде `\uXXXX`-последовательностей (`json.dumps(ensure_ascii=True)`),
которые `json.loads` разворачивает обратно.

**Почему так.** `.bat` обязан оставаться чистым ASCII. cmd.exe читает
файл в текущей кодировке, и любой кириллический байт в нём — это лотерея
с кодовой страницей, BOM и «Сохранить как» в блокноте. ASCII переживает
всё: копирование, пересохранение, zip, diff. Кириллица живёт в JSON
эскейпами и превращается в нормальный текст уже внутри Python.

## Пересборка `.bat`

`.bat` генерируется, руками его править не надо. Меняешь
`launcher_src/te1_engine.py` или `launcher_src/fixes_rus.json` — и:

```bash
python3 tools/build_launcher.py          # собрать заново
python3 tools/build_launcher.py --check  # проверить, не устарел ли .bat
python3 tools/test_launcher.py           # полный самотест на data_samples
```

`tools/test_launcher.py` собирает из `data_samples/` поддельную папку игры,
распаковывает движок из `.bat` тем же способом, что и PowerShell,
накатывает оба мода, проверяет результат поточными проверками, потом
откатывает и сверяет файлы побайтово.

## Как лаунчер понимает, что ты уже наигрался

Тут есть подвох, из-за которого первая версия работала неправильно.

`TheEscapists.exe` — это **не игра**. Это маленькая морда (2.4 МБ) с кнопкой
Play: она закрывается и запускает настоящую игру — `TheEscapists_rus.exe`,
`TheEscapists_eur.exe` или `TheEscapists_pol.exe` (8 МБ каждая, по языку).
Ждать процесс, который запустил лаунчер, бесполезно: он умирает через
секунду, а игрок ещё даже не нажал Play.

Поэтому лаунчер следит **за всеми exe игры в папке** (по именам процессов,
через `tasklist`):

* пока жива морда или запущена игра — ждём, ничего не сбрасываем;
* морда закрылась, а игра ещё не появилась — ждём до **8 секунд**
  (`--handover`): как только игра появится, снова переходим к ожиданию;
* игра закрылась — ждём ещё **2 секунды** (`--exit-grace`) на всякий случай,
  и только потом возвращаем файлы;
* закрыл морду, так и не нажав Play — через те же 8 секунд лаунчер напишет
  `The game never started` и всё равно вернёт файлы.

Обе задержки меняются:

```
py mods\te1_engine.py --handover 15 --exit-grace 5
```

Если `tasklist` по какой-то причине недоступен, наблюдение за процессами
просто не работает, и остаются одни задержки — то есть файлы всё равно не
сбрасываются раньше, чем через 8 секунд после закрытия морды.

## Если что-то не работает

| симптом | причина и что делать |
|---|---|
| `ERROR: TheEscapists.exe was not found` | `.bat` лежит не в папке игры |
| `ERROR: Python 3 was not found` | поставить Python с python.org с галочкой Add Python to PATH |
| `ERROR: this folder cannot be written to` | игра в `Program Files`; запустить `.bat` правой кнопкой → «Запуск от имени администратора» |
| `ERROR: the mod engine could not be unpacked` | нет PowerShell либо `.bat` обрезан при скачивании |
| игра не запускается, ругается на файлы | `py mods\te1_engine.py --restore` — вернёт оригиналы |
| перевод не меняется | мод Better Translate правит только `*_rus.dat`; если играешь на английском — включи русский язык в игре |
| моды сбрасываются, едва нажмёшь Play | увеличь `--handover` (см. «Как лаунчер понимает, что ты уже наигрался») |
| файлы не возвращаются после выхода | закрой это окно и запусти лаунчер снова — он сам всё восстановит при старте; либо `py mods\te1_engine.py --restore` |
| `*_rus.dat: unreadable (encrypted?)` | файл зашифрован; этот лаунчер такие не правит |
