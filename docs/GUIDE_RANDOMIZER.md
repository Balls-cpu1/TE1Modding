# Гайд: как запустить рандомайзер предметов

Для The Escapists 1 (PC / Steam), русская версия.

Рандомизация срабатывает **при каждой загрузке карты** и **при перезаходе**,
но **не между днями** — внутри одного забега предметы ведут себя стабильно.

---

## Шаг 1. Установить Python (один раз)

1. Открой <https://www.python.org/downloads/> и скачай установщик.
2. Запусти его и **обязательно поставь галочку** `Add Python to PATH`
   (внизу первого окна установщика). Без неё команды `py` и `python`
   работать не будут.
3. Жми `Install Now`, дождись конца.

Проверка: нажми `Win + R`, набери `cmd`, Enter. В чёрном окне набери

```
py --version
```

Должно написать что-то вроде `Python 3.12.4`. Если пишет «не является
внутренней или внешней командой» — переустанови Python с галочкой
`Add Python to PATH`.

---

## Шаг 2. Положить файлы в одну папку

Тебе нужны три файла, и лежать они должны **вместе**:

| файл | зачем |
|---|---|
| `te1_randomizer.py` | сам рандомайзер |
| `randomizer_auto.bat` | запуск авто-режима двойным щелчком |
| `randomizer_restore.bat` | откат к оригиналу двойным щелчком |

Положи их, например, в `C:\Games\TE1mod\`.

> В папку с самой игрой (`Program Files`) класть ничего не нужно —
> скрипт сам найдёт игру по пути
> `C:\Program Files (x86)\Steam\steamapps\common\The Escapists`.

---

## Шаг 3. Запустить

### Способ А — двойным щелчком (проще всего)

Дважды щёлкни **`randomizer_auto.bat`**.

Windows спросит «Разрешить этому приложению вносить изменения?» — жми **Да**.
Это нужно потому, что игра лежит в `Program Files`, а писать туда без прав
администратора нельзя.

### Способ Б — через командную строку

1. Пуск → набери `cmd`.
2. Правой кнопкой на «Командная строка» → **Запуск от имени администратора**.
3. В открывшемся окне:

```
cd /d "C:\Games\TE1mod"
py te1_randomizer.py --auto
```

---

## Шаг 4. Ответить на три вопроса

Скрипт спросит (в квадратных скобках — значение по умолчанию,
оно подставится, если просто нажать Enter):

```
  Папка игры: C:\Program Files (x86)\Steam\steamapps\common\The Escapists
  Языки в Data: eng, fre, ger, ita, pol, rus, spa
Язык(и) для правки, через пробел (или 'all') [rus]:
Уровень хаоса 1-4 (1=мягко, 4=полный) [2]:
Обновлять файл раз в N секунд [2]:
Запустить игру сейчас? (y/n) [y]:
```

**Язык** — по умолчанию стоит `rus`, просто нажми Enter. Игра читает
только один файл, тот, что соответствует языку в настройках, поэтому
остальные шесть трогать незачем. Если вдруг рандомизации не будет видно —
попробуй ответить `all`, тогда правятся все семь.

**Уровень хаоса** — сколько статов менять у предмета:

| | что будет |
|---|---|
| `1` | мягко, пара полей у предмета |
| `2` | заметно, но играбельно — рекомендую начать с этого |
| `3` | сильно: подушка ломает стены, ложка режет решётки |
| `4` | полный хаос, почти всё сломано |

**Обновлять раз в N секунд** — можно оставить `2`. Это как часто скрипт
кладёт в файл новую случайную версию. На производительность не влияет.

**Запустить игру сейчас?** — советую ответить **`n`** и запустить игру
через Steam как обычно. Так надёжнее: Steam корректно подхватит сессию,
достижения и облачные сохранения.

---

## Шаг 5. Играть

После ответов появится такое:

```
=== АВТО-РЕЖИМ: рандомизация при каждой загрузке карты ===
  бэкап создан: items_rus.dat.bak
  файл: items_rus.dat (<число> предметов, <число> байт, utf-16-le)
  хаос 2, обновление раз в 2 сек

  Держи это окно открытым, пока играешь.
  Остановка: Ctrl+C

  [17:41:49] версия #1 (сид 1250691762, 82 предметов)
  [17:41:51] версия #2 (сид 1307783770, 83 предметов)
```

(числа будут твои — строка `версия #N` показывает сид и сколько предметов
перетасовано в этой версии)

Дальше запускай игру через Steam и играй. **Окно скрипта не закрывай** —
оно должно работать всё время, пока ты играешь.

Что ты увидишь в игре:

| ситуация | что происходит |
|---|---|
| загрузил карту | статы предметов **новые** |
| идут дни внутри забега | статы **те же самые** |
| вышел в меню, зашёл снова | статы **снова новые** |
| загрузил сохранение | статы такие, какие были в момент загрузки |

---

## Шаг 6. Остановить и вернуть оригинал

**Остановить:** в окне скрипта нажми `Ctrl + C`. Он спросит
`Вернуть оригинальный items_*.dat? (y/n)` — нажми `y`.

**Вернуть оригинал позже:** двойной щелчок на **`randomizer_restore.bat`**
или команда

```
py te1_randomizer.py --restore
```

Оригинал всегда лежит рядом, в `Data\items_rus.dat.bak` — скрипт создаёт
его при первом запуске и больше не перезаписывает.

---

## Почему это работает именно «на карту», а не «на день»

В байткоде игры (фрейм `game`, группа событий #425, условие «начало фрейма»)
есть единственное чтение списка предметов:

```
INI_ITEMS: открыть файл "Data\items_" + <язык> + ".dat"
```

Оно выполняется один раз при входе во фрейм `game`, то есть при каждой
загрузке карты. Между днями файл не перечитывается — проверено по
`dumps/game_events.txt`. Скрипт просто держит в файле свежую случайную
версию, и игра подхватывает её ровно в момент загрузки карты.

Две детали, которые делают это безопасным:

- **Размер файла не меняется.** Случайная версия добивается пустыми
  строками ровно до исходного размера. Валидатор `val.dat` проверяет
  именно размер, поэтому `val.dat` трогать не нужно и игра не ругается.
- **Запись атомарная** (временный файл + переименование). Игра физически
  не может прочитать файл наполовину записанным. Если файл в этот момент
  занят игрой, скрипт напишет «файл занят игрой — подожду» и повторит.

## Если что-то пошло не так

**Первым делом запусти диагностику** — она покажет, что скрипт видит
в папке игры:

```
py te1_randomizer.py --diag
```

Она напечатает список `items_*.dat` с размерами, открытый это текст или
шифр, есть ли бэкап и **изменён ли файл прямо сейчас**:

```
  items_eng.dat            16796 байт | открытый текст, utf-16-le, предметов 128
                         бэкап: есть | СЕЙЧАС ИЗМЕНЁН
  items_rus.dat            16796 байт | открытый текст, utf-16-le, предметов 128
                         бэкап: есть | СЕЙЧАС ИЗМЕНЁН

  val.dat: 210 байт
    хеш размера items_eng.dat: совпадает
```

Пришли мне этот вывод, если что-то не так — по нему сразу видно причину.

### Если диагностика пишет «СЕЙЧАС ИЗМЕНЁН», а в игре ничего не меняется

Значит, файл правится, но не факт, что игра его читает. Проверь это
в лоб — запусти **метку**:

```
py te1_randomizer.py --mark
```

или двойной щелчок на **`randomizer_mark.bat`**.

Метка **меняет имена предметов местами**: `[0] <-> [1]`, `[2] <-> [3]` и
так далее. Размер файла при этом не меняется ни на байт (тот же набор
байтов, просто переставлен), так что сломать ничего нельзя.

Зайди в игру и посмотри на названия предметов:

- **названия перепутаны** → игра файл читает, значит, и рандомайзер
  работает. Тогда «ничего не изменилось» означает, что изменения попали
  в поля, которые незаметны глазу, — подними уровень хаоса до 3–4.
- **названия обычные** → игра этот файл не читает. Напиши мне, это
  меняет всё.

Вернуть имена: `randomizer_restore.bat` или `py te1_randomizer.py --restore`.

| что написано / что происходит | что делать |
|---|---|
| `! НЕТ ПРАВ НА ЗАПИСЬ в папку игры` | запусти от имени администратора (см. Шаг 3) |
| `ЗАШИФРОВАН (этот скрипт такие не правит)` | твои `.dat` зашифрованы, этот скрипт их не трогает — напиши мне, это чинится отдельно |
| `! в Data нет items_*.dat` | скрипт не нашёл папку игры; впиши путь к ней вручную, когда он спросит |
| `! Python не найден` | см. Шаг 1, не забудь галочку `Add Python to PATH` |
| `файл занят игрой - подожду` | это нормально, скрипт повторит сам |
| в диагностике `= оригиналу`, хотя скрипт работает | скрипт не дописывает файл — пришли вывод диагностики |
| игра не запускается / ругается на файлы | запусти `randomizer_restore.bat`, затем в Steam: свойства игры → «Проверить целостность файлов» |
| рандомизации не видно | проверь, что окно скрипта открыто и в нём бегут строки `версия #N` |

---

## Что именно меняется

Трогаются только игровые статы:
`Weapon`, `Digging`, `Chipping`, `Cutting`, `Unscrewing`, `HP`, `FAT`,
`Gift`, `Decay`, `Buy`, а на уровне хаоса ≥ 2 ещё и `Illegal` (нелегальность).

**Не меняются никогда:** `Name` (имя), `Craft` (текст рецепта), `Found`,
`Desk`, `NPC_carry`, `Outfit`, `Info`, `CamDis`. То есть названия предметов,
рецепты крафта и то, где предмет появляется, остаются родными — ломается
только то, что предмет умеет.

---

## Режим «один раз» (если не нужен авто)

```
py te1_randomizer.py
```

Перетасует один раз и выйдет. Предметы останутся такими до следующего
запуска скрипта — при перезаходе на карту статы **не** изменятся.
Дополнительно спросит сид: число делает результат повторяемым,
пусто — каждый раз разный.
