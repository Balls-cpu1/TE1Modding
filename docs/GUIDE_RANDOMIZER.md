# Гайд: рандомайзер предметов для The Escapists 1

PC / Steam, русская версия.

Два файла, оба запускаются двойным щелчком:

| файл | что делает |
|---|---|
| **`randomize.bat`** | перетасовывает предметы и сразу закрывается |
| **`restore.bat`** | возвращает оригинальные предметы |

Открыл `randomize.bat` → окно мелькнуло и закрылось → предметы перетасованы.
Хочешь другой набор → открой ещё раз. Каждый запуск даёт новый случайный
набор.

---

## Установка (один раз)

1. Поставь Python с <https://www.python.org/downloads/>.
   При установке **обязательно** поставь галочку `Add Python to PATH`.
2. Положи в одну папку (например `C:\te1\`) три файла:
   `te1_randomizer.py`, `randomize.bat`, `restore.bat`.

В папку игры ничего класть не нужно — скрипт сам найдёт её по пути
`C:\Program Files (x86)\Steam\steamapps\common\The Escapists`.

Проверка, что Python встал: `Win + R` → `cmd` → `py --version`.
Должно написать `Python 3.x.x`.

---

## Как пользоваться

1. **`randomize.bat`** — открой, дождись щелчка UAC («Да»).
2. Запусти игру и **зайди на карту**.

Статы подхватываются именно при загрузке карты: игра читает список
предметов один раз при входе во фрейм `game` и больше к файлу не
обращается. Поэтому:

| ситуация | статы |
|---|---|
| зашёл на карту после `randomize.bat` | новые |
| идут дни внутри забега | те же |
| вышел в меню, зашёл на ту же карту | те же, что были при загрузке |
| снова открыл `randomize.bat` и зашёл на карту | снова новые |

3. Надоело — **`restore.bat`**, и предметы вернутся к родным.

---

## Что именно перетасовывается

**Названия** — превращаются в случайный набор знаков вроде `Ъ~4щнэОЖЯЩ@ПР`.
**Описания** (`Info`) — тоже.

**Статы** — у предмета случайно меняются, добавляются и исчезают:
`Weapon`, `Digging`, `Chipping`, `Cutting`, `Unscrewing`, `HP`, `FAT`,
`Gift`, `Decay`, `Buy`, `Illegal` (нелегальность).

**Не трогается:** `Craft` (текст рецепта) — чтобы крафт продолжал работать.
Пустые слоты предметов тоже не трогаются.

Правится только `items_rus.dat` — тот файл, который читает русская версия.
Остальные шесть языков не затрагиваются.

---

## Почему ничего не ломается

- **Размер файла не меняется ни на байт.** Валидатор игры (`val.dat`)
  проверяет именно размер, поэтому `val.dat` трогать не нужно и игра
  не ругается. Названия подбираются ровно в ту же байтовую длину,
  что и исходные.
- **Оригинал лежит рядом** — `Data\items_rus.dat.bak`. Создаётся один раз
  при первом запуске и больше не перезаписывается, поэтому `restore.bat`
  всегда возвращает настоящие родные предметы.
- **Запись атомарная** (временный файл + переименование), игра не может
  прочитать файл наполовину записанным.

---

## Если что-то не так

Окно `randomize.bat` закрывается само только при успехе. Если оно
**осталось открытым** — там написана причина:

| что написано | что делать |
|---|---|
| `! НЕТ ПРАВ НА ЗАПИСЬ в папку игры` | запусти `.bat` правой кнопкой → «Запуск от имени администратора» |
| `! Python не найден` | см. «Установка», не забудь `Add Python to PATH` |
| `! в Data нет items_*.dat` | скрипт не нашёл папку игры |
| `зашифрован` | твои `.dat` зашифрованы, напиши мне — это чинится отдельно |
| игра не запускается | `restore.bat`, затем в Steam: свойства игры → «Проверить целостность файлов» |

Дополнительно есть команды для диагностики (в консоли, из папки со скриптом):

```
py te1_randomizer.py --diag    показать состояние файлов, ничего не меняя
py te1_randomizer.py --restore откат (то же, что restore.bat)
```

`--diag` печатает размеры всех `items_*.dat`, есть ли бэкап и изменён ли
файл сейчас. Пришли этот вывод, если что-то непонятно.
