# Как добавить СВОЮ МЕХАНИКУ в The Escapists 1 (PC)

Пример цели: дверь, открывающаяся только в форме охранника / только для медика
(такие двери были в мобильной версии).

## Главный вывод: механики — это НЕ данные, это «код» (события Fusion)

- В exe **один игровой фрейм `game`**; все тюрьмы строятся в рантайме.
- Его чанк `Frame Events` (13117) после расшифровки = **2 420 852 байта** событий
  (расшифровано `toolkit/te_crypto.py`, дамп — `work/game_events.bin`). Это и есть весь
  «код» механик. Двери, форма, проверки — всё там.
- Значит, новая механика = правка байткода событий (или пересборка в Fusion), а не правка
  `items_*.dat`/`data_*.dat` как с предметами.

## Хорошая новость: нужные «кирпичики» УЖЕ в PC-exe

Из 774 объектов (расшифровано из `Frame Items`):
- `Door - outfit`  (handle **501**) — дверь, открывающаяся по форме (тот самый мобильный кейс);
- `Door - noKey` (518), `Door - Cell` (174), `Door - Utility (vents)` (457) и др. типы дверей;
- `Outfit - Guard` (248/700), `Outfit - Inmate` (249/701), `Outfit - POW`, `overalls_outfit`;
- медицинские объекты: `Container - MEDICAL` (269), `Bed - Medical` (234), `medic spot` (421).

То есть ассеты «двери по форме» и «медицинской зоны» в PC-версии присутствуют — мобильная
версия просто подключает их в событиях. В PC они есть в банке объектов, но не разведены по
тюрьмам в событиях фрейма `game`.

## Как это реализовать (маршруты)

| Маршрут | Суть | Реальность |
|---|---|---|
| **B (рекомендую)** | Декомпилировать exe→MFA (NebulaFD/CTFAK), открыть в **Fusion 2.5**, в Event Editor фрейма `game` добавить условие «текущая форма = Guard/Medic» → действие «открыть дверь». Использовать готовые объекты `Door - outfit`/`Outfit - Guard`. | Supported-путь; нужен платный Fusion 2.5. |
| Байт-патч событий | События теперь читаются (`te_crypto.py`), но формат байткода событий — отдельная большая реверс-задача; правку нельзя проверить без запуска игры. | Возможно, но не для первого шага. |
| Только данные | Сделать дверь требующей «ключ», который носят только охранники. | Это «имеет предмет», а НЕ «одет в форму» — лишь аппроксимация. |

## Почему нельзя просто правкой .dat
`items_*.dat`/`data_*.dat` описывают предметы/тексты, но НЕ условие открытия двери.
Условие «одет в форму» живёт в событиях фрейма `game`. Поле `Outfit=` у предмета лишь
говорит игре, что это форма; сама проверка «форма надета → открыть» — в событиях.

## Примечание
Приложенные `items_*.txt/speech_*.txt/data_*.txt` в песочницу НЕ попали (их нет на диске),
поэтому в этот тёрн я их не использовал. Для задачи «дверь по форме» они и не нужны.
