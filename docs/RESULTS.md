# Результаты сессии: свой предмет в The Escapists 1

## Что прочитано
Распакованы `workspace1.zip` (дамп образа exe: 3948 PNG, `images.csv`, инструменты,
исходники CTFAK) и `workspace2.zip` (документация, `escapists_mod.py`, справочники,
сами exe в `uploads/*.exe.txt`, `val.txt`, легаси `items_dec.dat`).

## Главный прорыв: снято ограничение «иконка = только в exe, и её не расшифровать»
Ранее (см. `MODDING_THE_ESCAPISTS.md` §4 / `EXE_ANALYSIS.md` §3) дешифровка чанков
с анимациями объектов (flag=3) **не поддавалась**, поэтому нельзя было сопоставить
«ID предмета → кадр иконки». Теперь это **сделано и проверено**:

- `toolkit/te_crypto.py` — точный порт `CTFAK-Native/encryption.cpp`+`wrapper.cpp`
  (проверен байт-в-байт против скомпилированного C++; ключевой поток `191b840cc64e...`).
- `toolkit/te1_icons.py` — парсит exe → объект `Items` (handle 184) → карта ID→иконка.
- `toolkit/item_icon_map.json` — 281 слот: ID 0..278 + запасные 279/280.
- `toolkit/all_icons_sheet.png`, `toolkit/icons_90_169.png` — визуальная сверка
  (иконка совпадает с именем предмета).

Соответствие: **ID = порядковый слот** среди непустых анимаций `0,1,2,5,6,7,8,9,10`
(3,4 вырезаны), по 32 направления в анимации. Примеры: 25 Crowbar→h14, 55 empty→h153,
96 Toothbrush→h812, 278 Thruster→h3957.

## Готовый пайплайн правки данных
`extracted/ws2/escapists_mod.py`: `set-item` + `enc --same-size` / `val` — проверено
на легаси-файле (создаёт запись, честно падает на `--same-size`, если файл длиннее,
и предлагает пересобрать `val.dat`).

## Статус маршрутов добавления предмета
| Маршрут | Статус |
|---|---|
| A занять ID (иконка от ID) | **готов** — карта даёт иконку любого ID осознанно |
| оживить слот 279/280 | **готов** — иконки уже в exe, нужно дописать запись в `items_*.dat` |
| C своя иконка (байт-патч exe) | записи картинок найдены (handles/размеры), но точный per-pixel LZ4 re-encode «в тот же размер» — экспериментальный; завершается на вашей 16×16 PNG |
| B своя иконка через Fusion | вне песочницы (нужен платный Fusion 2.5) |
