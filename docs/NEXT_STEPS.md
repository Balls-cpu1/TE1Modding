Все 20 хешей из твоего `val.dat` разобраны. Формула подтверждена на 100%:

```
хеш = md5("l0l_" + размер_файла_в_байтах)
```

## 2. Что выяснилось про присланные файлы

| Файл | Размер | Вердикт |
|---|---|---|
| `data_eng.dat` | 47020 | ✅ **Тот самый файл.** Не зашифрован (обычный текст), хеш сошёлся с `val.dat`. Править можно напрямую, но следить за размером |
| `items.dat` | 8400 | ⚠️ **Не тот файл.** Это легаси-копия «без языка»: внутри всего **128 предметов (ID 0…127)**, старая версия формата. Игра проверяет и читает **`items_eng.dat` (16925 байт)** / `items_rus.dat` (35234) |
| `speech.dat` | 41800 | ⚠️ Тоже «без языка», игра проверяет `speech_eng.dat` (54688) / `speech_rus.dat` (107050) |

**Вывод:** для мода нужны `items_eng.dat` и/или `items_rus.dat` — их и присылай. Забавно, что у тебя в папке лежат старые no-language копии: они, судя по всему, вообще не используются игрой (наследие ранних версий).

Кстати, про `rus`: хеш `data` для русского **совпадает с английским** (47020). То есть `data_rus.dat` скорее всего нет вообще, и русская версия берёт английский data-файл, а локализуются только предметы и реплики. Так что если играешь в русскую — правь `items_rus.dat`.

## 3. Про `.exe`: как передать

Тот же трюк, что и с `.dat`: **переименуй, а не «Сохрани как»**.

* В проводнике: правый клик → «Переименовать» → `TheEscapists_exe.txt`. Это побайтовая копия, содержимое не меняется.
* ⚠️ Не открывай бинарные/зашифрованные файлы в блокноте и не сохраняй — «Сохранить как» перепишет байты (BOM, кодировка, переводы строк) и **сломает `val.dat`**. Только переименование!

Про размер: у Fusion-игр exe бывает 100–300 МБ. Если такой файл в чат не влезет или не переживёт между сообщениями, есть три варианта:

1. **Exe мне вообще не нужен** (для маршрута B). Декомпиляция — локальная задача, инструменты под Windows: делаешь её у себя, а мне присылаешь скриншоты и дампы. Это самый удобный путь.
2. Если хочется, чтобы я копался в самом exe — сначала попробуй залить переименованный; если не пройдёт, режем 7-Zip'ом на тома по 20 МБ (каждый тоже переименовать в `.txt`).
3. Либо я напишу тебе маленький локальный скрипт-сканировщик: он на твоей машине найдёт в exe образ картинок и выложит только иконки предметов + отчёт (пара сотен килобайт вместо 200 МБ).

## 4. Маршрут B, пошагово

### Подготовка (5 минут)
1. Скопируй папку игры целиком в стороннее место — это твой бэкап. Steam → «Проверить целостность файлов» тоже вернёт всё как было.
2. Поставь **.NET 6** (Runtime/Desktop или SDK) — нужен для CTFAK.
3. Скачай **CTFAK 2.0**: репозиторий `CTFAK/CTFAK2.0` → вкладка **Actions** → последняя успешная сборка → артефакт **CTFAK** → распаковать. (Альтернативы: `AITYunivers/CTFAK-UnEx` — иногда работает лучше на «сложных» играх; `AITYunivers/NebulaFD` — современный декомпилятор в MFA.)
4. Поставь **Clickteam Fusion 2.5** — без него собрать exe заново не выйдет. На Steam он регулярно уходит по −75%; есть подписка Fusion 2.5+. Free-версия без расширений TE1, скорее всего, не соберёт.

### Шаг 1. Найти иконки предметов в exe
1. Запусти `CTFAK.Cli.exe`, вставь путь к `TheEscapists.exe` (Shift + правый клик по файлу → «Копировать как путь»).
2. Выбери режим **Sorted Image Dumper** (тип `6`) — выгрузит картинки, разложенные по объектам и кадрам, в папку `Dumps`.
3. Ищи объект, у которого **≈279+ кадров** и содержимое похоже на иконки предметов. Если такой найдётся — гипотеза «иконка предмета = кадр № ID» подтверждена официально.
4. Заодно попробуй **Extension Dumper** — игра использует расширения Fusion, их нужно будет доустановить, чтобы MFA открылся.

### Шаг 2. Получить MFA и открыть его
1. В CTFAK выбери **Export as MFA** (или прогони NebulaFD) — получишь `.mfa` (по рассказам, у TE1 внутри 12 фреймов — вероятно, по фрейму на тюрьму).
2. Открой в Fusion 2.5. Будь готов, что декомпиляция «неполная»: теряются имена глобальных переменных, комментарии, иконки объектов; иногда приходится подсовывать расширения (`Extension Dumper` их достаёт).

### Шаг 3. Добавить свой предмет
1. Правим данные нашим скриптом (пример для нового ID, либо занять 55/223/вырезанный предмет):
   ```bash
   python escapists_mod.py dec items_eng.dat -o work.dat          # если зашифрован
   python escapists_mod.py set-item work.dat --id 279 --create \
       --from-id 25 --set "Name=Master Key" --set "Weapon=5" --set "Craft=80_Crowbar, Duct Tape"
   python escapists_mod.py enc work.dat -o items_eng.dat --same-size items_eng.dat
   ```
2. В Fusion: в объект-иконку добавить кадр для нового ID (в Animation Editor) — или, что чище, добавить событие «Load Frame from disk» и держать свои картинки в `Data/images/` файлами PNG. Второй вариант избавит от пересборки exe при каждой правке арта.
3. Собрать exe (File → Build), положить рядом с папкой `Data`.

### Шаг 4. Что мне присылать по ходу
* Скриншоты Fusion: список объектов фрейма, Animation Editor объекта-иконок, Event Editor — **скриншоты в чат отлично проходят**.
* Лог/отчёт CTFAK (`.txt`).
* Список файлов из `Dumps` (можно тем же «сохранить список как .txt» — или просто скриншот проводника).
* Дамп нужного объекта с иконками (PNG) — по нему сделаем кадр для твоего предмета.

### Быстрый способ проверить папку `Data` (PowerShell)
```powershell
Get-ChildItem "C:\Program Files (x86)\Steam\steamapps\common\The Escapists\Data" |
  Select-Object Name, Length | Sort-Object Name | Format-Table -AutoSize
```
Сравни размеры с таблицей из раздела 1 — сразу увидишь, какие файлы «настоящие».
